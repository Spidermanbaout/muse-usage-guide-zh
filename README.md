# Meta Muse 使用教程：从第一条任务到日常目标

> 本文介绍 Meta 的个人 AI 助手 Muse。它可以通过对话理解目标、使用已连接的应用和浏览器推进任务，并在后台继续处理长期事项。本文基于 Muse 官方介绍整理，更新于 2026-10-10；界面、入口和功能可能随产品更新而变化。

## Muse 是什么

普通聊天通常以回答问题为主；Muse 更像一个可以持续协助你完成事务的个人 AI 助手。你可以告诉它想达到的结果，由它拆解计划、推进后续步骤，并在需要你决定时回来询问。它支持聊天、长期目标、后台任务，也可以生成文档、PDF、网页等可交付内容。[Muse 官方介绍](https://muse.ai/) · [Muse 设计说明](https://introducing.muse.ai/)

可以通过 Muse 的网页、移动应用、Mac 应用或 WhatsApp 与它交流。按官方入口登录或创建账号即可；能否使用某个入口、功能或连接服务，以 Muse 当前页面显示为准。[Muse 官方入口](https://muse.ai/)

## 第一次使用：先从一个小任务开始

第一次打开时，先选一个容易核对结果的任务。比如让 Muse 整理一封邮件的要点、列出本周日程中的冲突，或为周末出行列出方案。先观察它如何理解目标、使用哪些信息、在哪里暂停让你确认。

可以这样描述任务：

```text
请帮我安排下周三的半天行程。

目标：上午处理工作，下午在市区看牙。
约束：不要安排在 12:00–13:00；通勤最多 40 分钟。
先查我的日历并给出建议，不要创建或修改日历事件。
列出你参考的时间和地点；信息不足时先问我。
```

这段提示说明了目标、约束、可使用的信息和行动边界。日常小事可以直接说；涉及多个步骤或外部操作时，最好把“先整理方案”和“确认后再执行”说清楚。

## 把一个目标变成持续推进的计划

对需要多天完成的事情，明确目标、时间范围和判断标准，再让 Muse 列出计划。例如：

```text
帮我在未来四周建立每周三次的跑步习惯。

先问我目前的运动情况和可安排时间，再给出循序渐进的周计划。
每周日总结完成情况并提出下一周安排。
不要替我购买装备、报名活动或联系他人；这些事情先给建议，等我确认。
```

确认计划后，可以继续补充偏好或调整安排。你也可以把不同主题放在不同的 side chat 中，减少项目之间的信息混杂；在 Goals 页面查看长期事项及其进展。Muse 的设计说明提到，Goals 用于查看目标和计划，后台任务可以在你离开应用后继续推进。[Muse 设计说明](https://introducing.muse.ai/)

## 连接应用前，先想清楚需要什么

连接邮件、日历或其他服务后，Muse 可以在你授权的范围内读取信息或执行操作。先从完成当前任务所需的应用开始，查看连接和权限设置；如果只需要查询，就优先选择只读权限。不要为了“以后可能用到”而一次连接所有账号。

不要把密码、验证码、支付卡号或 API 密钥直接粘贴在聊天里。登录服务时使用 Muse 提供的安全凭据流程，并只连接你愿意授权的账号。Muse 官方安全说明介绍了凭据隔离、操作审批和活动可见性等设计，但 AI 仍可能理解错任务或遗漏细节，所以重要操作要亲自核对。[Muse 安全说明](https://security.muse.ai/)

## 需要外部操作时，仔细检查审批卡片

Muse 可以协助起草邮件、填写网页表单或准备购物流程。发送邮件、购买商品等可能产生实际后果的操作，需要留意 Muse 提示的审批。确认前核对：

- **收件人或商家**是否正确；
- **邮件内容、商品、数量和总价**是否符合你的要求；
- **日期、地点、取消条件或其他关键条款**是否清楚；
- 审批所覆盖的具体动作，是否正是你刚才授权的内容。

如果审批信息和你预期不一致，选择拒绝或先修改任务。可以让 Muse 先“准备草稿/清单，但不要发送或下单”，等你确认细节后再继续。Muse 会在你需要检查时展示操作审批，并提供活动记录供你回看。[Muse 官方介绍](https://muse.ai/) · [Muse 安全说明](https://security.muse.ai/)

## 查看进展、记忆和生成内容

- **活动记录：** 点击 Muse 头像查看它正在处理的事情、已完成的步骤和你授予的权限。
- **目标页面：** 回看长期目标及计划；发现方向不对时，直接在对话或目标页面调整。
- **设置和记忆：** Muse 的设计说明提到，设置和记忆文件可以查看、编辑。定期检查长期保存的偏好是否准确、是否仍然需要。
- **生成内容：** 对行程、报告、清单或追踪面板，可以直接要求它生成合适的文档或交互式内容，并检查关键数据后再使用。

## 实用提示模板

```text
我希望完成：[具体结果]

背景：[必要的账号/文件/时间/偏好信息]
限制：[预算、期限、不能做的事]
需要你做：[查询、比较、起草、计划或执行]
需要我确认的操作：[发送、发布、购买、预约等]
完成标准：[什么结果算完成]

先给我简要计划和你需要访问的信息。
涉及对外发送、购买、预约或其他重要操作时，先停下来让我检查并确认。
完成后总结做了什么、还缺什么，以及我可以在哪里核对结果。
```
